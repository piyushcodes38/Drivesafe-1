A browser-based concept that estimates prolonged eye closure from face landmarks, plays a repeating Hindi warning alert, and lets the user prepare a message for SMS or WhatsApp. Camera processing is intended to remain on this device.

Prototype limitations: eye-blink blendshapes are only a rough signal, not a medical or safety-grade drowsiness detector. Lighting, glasses, camera angle and model errors can affect results. A 1.5-second threshold is an experimental setting, not a validated universal threshold. Camera frames are processed locally by this page; the model files are fetched from public CDNs the first time; this offline-ready version caches successful downloads for later use when hosted over HTTPS.
