SOS buttons open your SMS app or WhatsApp with a prepared message. You must review and press Send yourself. This demo does not send messages in the background or contact emergency services automatically.
Offline setup: open this site online once, then press “Start camera monitor” and wait for monitoring to begin. Reload the page, then test airplane mode. This requires HTTPS (for example, GitHub Pages) and a browser that supports service workers. SOS sending and some location services still need connectivity.
Prototype limitations: eye-blink blendshapes are only a rough signal, not a medical or safety-grade drowsiness detector. Lighting, glasses, camera angle and model errors can affect results. A 1.5-second threshold is an experimental setting, not a validated universal threshold. Camera frames are processed locally by this page; the model files are fetched from public CDNs the first time; this offline-ready version caches successful downloads for later use when hosted over HTTPS.
